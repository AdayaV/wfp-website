# マシンアーカイブの出典と掲載方針

写真・年式・短い紹介・大会成績を中心とし、諸元は公表済みのエンジン・排気量・車両重量などに限定する。未確認の項目は空欄とし、他年式の値や目標値で補完しない。写真はチームが利用できる素材から年式を確認して追加し、出典ページの写真・図面は転載しない。

## 年式・名称の扱い

- 2005年・2006年は、WFP発足前の自動車部学生フォーミュラ班の車両として区別する。実名の **WF-01 / WF-01R** は変更しない。
- **WFP2011** はサイト内の統一表示名。参戦車両の存在は確認できるが、当時の固有名称は未確定。
- 2009年のチーム発足から、毎年一台ずつ製作したとは推定しない。2007・2009・2010・2012・2020・2021年は、独立した完成車両とその名称を確かめるまで自動追加しない。
- 特に2010年と2011年は、2011年のチーム記事に前年車両の製作遅延と改良が記されているため、別々の完成車両として数えない。
- 大会成績の「総合」と「ICVクラス総合」を混同しない。ベストエアロ賞は順位付きで表示する。
